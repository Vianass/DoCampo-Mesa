# Créditos das fotografias do catálogo

Fotografias ilustrativas para os dados fictícios do protótipo «Do Campo à Mesa». Não identificam produtores aderentes nem comprovam a origem, variedade, certificação biológica, denominação de origem ou características comerciais dos produtos. Usar cada fotografia apenas para o alimento efetivamente representado.

Cada página oficial foi consultada e identifica a fotografia como gratuita ao abrigo da [Unsplash License](https://unsplash.com/license), sem licença Unsplash+. A licença permite descarregar, copiar, modificar e distribuir as imagens, incluindo para fins comerciais; a atribuição é facultativa, mas fica preservada neste registo. Não permite vender imagens sem alterações significativas nem criar uma biblioteca concorrente do Unsplash.

## Correspondência dos alimentos

- `cheese.webp` representa queijo de cabra fotografado em Sonoma, nos Estados Unidos. Não usar para queijo da Serra, queijo fresco sem crosta, queijo de ovelha ou produtos com DOP.
- `leafy-greens.webp` representa couve kale. Não usar para espinafres, alface ou outra variedade específica de couve.
- `nuts.webp` representa nozes. Não usar para castanhas ou amêndoas.
- `strawberries.webp` representa morangos. Não usar para uvas ou figos.
- `onions.webp` representa cebolas. Não usar para alho-francês ou alho.
- Não foi acrescentada fotografia de ervas, alho-francês, uvas, figos, castanhas, amêndoas ou cereais em grão; para esses alimentos usar um placeholder até existir uma fonte correspondente.
